# caret

A minimal, MonkeyType-style typing game for code snippets.

**Play:** https://shplok.github.io/caret/

Type real functions across 8 languages (Python, JavaScript, TypeScript, C, C++, Java, Rust, assembly) with auto-indentation, a gliding caret, live WPM and accuracy, a results graph, and a local profile that tracks your bests.

## Run locally

```
npm install
npm run dev
```

Then open http://localhost:5173.
